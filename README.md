## 📖 About The Architecture

The **AI-Powered Utility Recommendation Architecture** provides an end-to-end ecosystem for discovering, testing, benchmarking, and chaining artificial intelligence tools into high-efficiency workflows.

### Repository Structure

- [`craly-web/`](./craly-web): Production Next.js 16 web application featuring:
  - 🛠️ **AI Tools Directory (`/tools`)**: Over 1,200+ curated AI utilities with category filtering, ratings, and pricing badges.
  - ⚡ **Automated Workflows (`/workflows`)**: Multi-step creative and technical pipelines with verified prompts.
  - ⚖️ **Comparison Engine (`/compare`)**: Multi-tool benchmark matrix with floating dock selector.
  - 🤖 **AURA AI Copilot (`CralyAiFab`)**: Google Gemini-powered conversational assistant equipped with real-time **Generative UI** widgets.
  - 💬 **Community Feed (`/posts`)**: Social collaboration hub for tested prompts and articles.

## 🚀 Quick Start

To launch the web interface locally:

```bash
# Navigate to web application directory
cd craly-web

# Install required dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your web browser.
